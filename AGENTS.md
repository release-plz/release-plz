# Agent guidance

## Pull requests

Include this checklist in the PR description and show it to the human
contributor for confirmation:

- [ ] I have read the [AI Policy][ai-policy] and the
  [contributing guidelines][contributing-guidelines].
- [ ] I reviewed the code myself before marking the PR as ready for review.

These are personal attestations. Do not check a box on the human's behalf or
infer confirmation from completed agent work. Leave any unconfirmed box
unchecked, and do not mark the PR ready for review until the human confirms
they reviewed the code. Check the [organization PR template][pr-template] for
updates before creating or updating a PR.

[contributing-guidelines]: https://github.com/release-plz/release-plz/blob/main/CONTRIBUTING.md
