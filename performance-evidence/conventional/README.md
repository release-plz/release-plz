# Borrow the message when checking conventional commits

Baseline: release-plz `6e42d3c2` (main); candidate: `b90e155b` (`codex/perf-borrow-conventional-message`).

`benches/conventional.rs` includes both exact production `diff.rs` files as Rust modules. Baseline is the unmodified main file copied to `baseline/diff.rs`; the measured candidate included the clean worktree file. The equivalent exact candidate source is packaged under `candidate/diff.rs` for portable reproduction. The included Cargo manifest can build the same harness using `cargo run --release --manifest-path <this-directory>/Cargo.toml -- before` (and `-- after`); the original measurements used the compiler command described below. Only the unrelated `SemverCheck` field type is stubbed because this microbenchmark does not compile the entire update engine. Both tested `Commit` types and both `is_conventional()` methods are real production source. Signatures and contributors are the real git-cliff types and are populated identically.

The original method clones the entire metadata-bearing commit and calls git-cliff's `into_conventional`, which copies and leaks the message. The replacement borrows it and invokes exactly the same parser version (`git-conventional 0.12.9`), preserving behavior. Both revisions are compiled together with `rustc -O`, against the same already-built workspace-lockfile dependencies. Exact compiler command is saved in `build-command.txt`; environment in `environment.txt`.

Cases: a short conventional message; a conventional message with approximately 1 KiB of body text and a breaking footer; a non-conventional message. Inputs include author name/email, committer name/email, username, PR number and a 40-character commit ID. Fixture construction is excluded from timing; result assertions execute before measurements. Each process warms up for 10,000 calls then measures 300,000 calls using `Instant` and `black_box`. Calls are explicitly bounded because the old method leaks one message on each call. Each revision runs in its own process, exiting before the next run.

Run command: `bash /workspace/perf-results/conventional/run.sh`, giving three alternating before/after pairs. Raw timings are in six JSONL files; elapsed_ns / iterations gives ns/call, and the summary uses the arithmetic mean of all three independent runs. Peak RSS is recorded separately to ensure the leaked baseline stays bounded. No builds or other benchmarks ran concurrently.

Validation: the same source-inclusion harness compiled with `rustc --test` and passed all 9 tests (baseline 4, candidate 5). This exercises the newly added behavior table and existing `diff.rs` tests. The production change also compiled and passed its regression test in the combined workspace validation checkout; see ../validation and ../README.md.
